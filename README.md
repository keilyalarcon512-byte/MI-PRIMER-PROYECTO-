# 🏍️ MotoSpeed - Tienda de Motocicletas

Este es mi primer proyecto web desarrollado con **HTML5** para practicar el control de versiones con **Git** y **GitHub**.

## 📋 Contenido del proyecto
* **`index.html`**: Estructura principal de la tienda con catálogo básico de motos y datos de contacto.

## 🛠️ Tecnologías usadas
* HTML5
* Git & GitHub

## 🚀 Cómo verlo
1. Clona este repositorio:
   ```bash
   git clone https://github.com
   ```
2. Abre el archivo `index.html` en tu navegador web favorito.
